# E-Commerce Sales & Customer Analytics System

A MySQL-based relational database project for managing and analyzing e-commerce customers, products, orders, payments, and sales performance.

## Project Overview

This project simulates the database of an e-commerce business. It stores customer information, product and category details, orders, and individual order items.

The database is designed to answer common business questions such as:

- How much revenue was generated?
- Which products generate the most revenue?
- Who are the top customers?
- Which product categories perform best?
- What is the monthly sales trend?
- Which payment methods generate the most revenue?
- Which customers belong to high-value segments?

## Tech Stack

- **Database:** MySQL 8.0+
- **Tool:** MySQL Workbench
- **Language:** SQL

## Main Analysis

### 1. Revenue Analysis

Calculates total revenue from completed orders while applying discounts.

```sql
SELECT ROUND(
    SUM(oi.quantity * oi.unit_price * (1 - oi.discount/100)), 2
) AS total_revenue
FROM orders o
JOIN order_items oi
    ON o.order_id = oi.order_id
WHERE o.status = 'Completed';
```

### 2. Category Performance

Identifies revenue generated by each product category.

### 3. Top Products

Ranks the top five products based on revenue.

### 4. Customer Analysis

Identifies customers with the highest total spending and number of completed orders.

### 5. Monthly Sales

Analyzes revenue month by month using `DATE_FORMAT()`.

### 6. Customer Segmentation

Uses a `CASE` statement to classify customers into:

- Platinum
- Gold
- Silver

based on total spending.

### 7. Product Ranking

Uses the `DENSE_RANK()` window function to rank products within their categories.

### 8. Customer Revenue Ranking

Uses a CTE with `DENSE_RANK()` to rank customers based on total revenue.

## Advanced SQL Features

### CTE

A Common Table Expression makes complex queries easier to structure and read.

Example:

```sql
WITH customer_revenue AS (
    SELECT c.customer_id,
           c.customer_name,
           SUM(
               oi.quantity * oi.unit_price *
               (1 - oi.discount/100)
           ) AS revenue
    FROM customers c
    JOIN orders o
        ON c.customer_id = o.customer_id
    JOIN order_items oi
        ON o.order_id = oi.order_id
    WHERE o.status = 'Completed'
    GROUP BY c.customer_id, c.customer_name
)
SELECT *
FROM customer_revenue;
```

### Window Function

`DENSE_RANK()` is used to rank customers or products without combining the individual rows.

```sql
DENSE_RANK() OVER (
    ORDER BY revenue DESC
)
```

### View

The project includes a reusable view called:

```text
completed_order_details
```

It provides a simplified reporting layer containing completed orders, customer details, products, categories, discounts, and line totals.

### Stored Procedure

The project includes:


It returns a customer's purchase history using an input customer ID.

Example:

```sql

```

3. Execute the complete script.
4. The script automatically:

   - Creates all tables
   - Inserts sample data
   - Creates the view
   - Creates the stored procedure
   - Runs example analysis queries
5. Refresh the Schemas panel and open the `ecommerce_analytics` database.
